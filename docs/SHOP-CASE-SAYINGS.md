# Shop — Case & Merch Sayings (pick-list)

Short cheeky sayings for the XTEINK X3 case stock designs (and bigger surfaces like notebook covers / tees). A working pick-list — grab what you like.

**Rules of thumb**
- **Short + bold prints best in filament** on a small case — aim 1–4 words. Longer lines go on notebook covers / tees.
- All below are **common-pool / generic phrases** → not copyrightable, free to use. (They're popular *because* they sell, and too common to get struck.)
- **Avoid:** a distinctive verbatim line from a specific in-copyright novel, and **trademarked** brand names/slogans (e.g. "Scholastic").
- Set type **BIG + chunky + high-contrast** for legibility at case size.
